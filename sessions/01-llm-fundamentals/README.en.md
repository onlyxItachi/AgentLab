**Duration:** Approximately 90 minutes

**Status:** Session-one lesson notes, glossary, Colab playground, structured-output walkthrough, and conceptual exercises are available; the live lesson can be adapted as needed.

## Goal and scope

Explain the basic relationship among language models, data representations, tool use, and output schemas.

**Learning map:** LLM → Token → Vector / Matrix / Embedding → Function / API / Tool → Structured Output / Schema.

This is the teaching order, not the literal execution pipeline of every model.
