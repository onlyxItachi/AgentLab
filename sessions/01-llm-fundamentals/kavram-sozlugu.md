# Oturum 1 sözlüğü

[Oturuma dön](README.md) | [English](glossary.md) | [Genel sözlük](../../docs/tr/kavram-sozlugu.md)

| Kavram | Bu oturumdaki anlamı |
|---|---|
| LLM | Bağlamdan hareketle sonraki metin parçalarını tahmin ederek metin üreten büyük dil modeli. |
| Token | Tokenizer'ın metinden elde ettiği ve modelin işlediği birim. |
| Vector | Sıralı sayılarla ifade edilen temsil. |
| Matrix | Sayıların satır ve sütunlarla düzenlenmiş hâli. |
| Embedding | Bir öğenin vektör olarak sayısal temsili. |
| Function | Çağrıldığında tanımlı bir görevi yapan kod. |
| API | Yazılımlar arası erişim kurallarını belirleyen arayüz. |
| Tool | Bir uygulamanın modele kullanıma açtığı işlev veya yetenek. |
| Structured output | Beklenen yapıya göre düzenlenmiş çıktı. |
| Schema | Çıktı veya başka veriler için yapı ve kısıtları tanımlayan şema. |
