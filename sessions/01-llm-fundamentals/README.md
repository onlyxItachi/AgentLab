Dil modeli, veri temsili, araç kullanımı ve çıktı şeması arasındaki temel ilişkiyi açıklamak.

**Öğrenme haritası:** LLM → Token → Vektör / Matris / Gömme → İşlev / API / Araç → Yapılandırılmış Çıktı / Şema.

Bu sıralama dersin anlatım sırasıdır; her modelin birebir çalışma akışını göstermez.
