# Session 1 glossary

[Back to session](README.en.md) | [Türkçe](kavram-sozlugu.md) | [General glossary](../../docs/en/glossary.md)

| Term | Meaning in this session |
|---|---|
| LLM | A large language model that generates text by predicting subsequent pieces in context. |
| Token | A unit produced by a tokenizer and processed by a model. |
| Vector | An ordered numeric representation. |
| Matrix | Numbers arranged in rows and columns. |
| Embedding | A numeric vector representation of an item. |
| Function | Code that performs a defined task when called. |
| API | An interface defining how software accesses functionality or data. |
| Tool | A function or capability an application makes available to a model. |
| Structured output | Output arranged according to an expected structure. |
| Schema | A definition of the structure and constraints of output or other data. |
