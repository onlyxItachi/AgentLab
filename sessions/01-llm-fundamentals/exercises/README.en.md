# Session 1: Draft exercises

[Back to session](../README.en.md) | [Türkçe](README.md)

1. Explain why the number of words in a sentence need not equal its number of tokens.
2. In your own words, distinguish proposing a tool call from actually running the tool. Which component decides whether to execute the call?
3. What question does schema compliance answer for a JSON object? Why must its content still be checked for correctness?
4. Run the [mini demo](../demos/structured-output/README.en.md) with one known and one unknown concept; observe how `found` changes.
5. Does proximity between two text embeddings, or a fluent model response, prove the content is correct by itself?

These questions are drafts; timing and how they will be used remain undecided.
